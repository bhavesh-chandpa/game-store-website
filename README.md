# 🎮 Game Store Website

A multi-page gaming storefront developed using **HTML, CSS, and JavaScript**. This project provides an interactive platform where users can explore games, browse offers, view game details, and manage their shopping cart and wishlist.

## ✨ Features

- **Game Catalogue:** Browse games across different genres.
- **Game Search:** Search for games by title, genre, or platform.
- **Game Details:** View game descriptions, artwork, prices, discounts, genres, and supported platforms.
- **Shopping Cart:** Add, remove, and manage games in the cart.
- **Wishlist:** Save favourite games for later.
- **Offers:** Explore discounted and free games.
- **Gaming News:** Browse gaming-related updates.
- **Local Storage:** Cart and wishlist data persist in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## 📂 Project Structure

- `Html_Files/` – Website pages
- `CSS/` – Stylesheets
- `JavaScript_Files/` – JavaScript functionality and game data
- `Images/` – Game artwork and website images
- `index.html` – Website entry point

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/bhavesh-chandpa/game-store-website
   ```

2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `Html_Files/home.html` using Live Server.

## ⚠️ Project Limitations

This is a front-end academic project and demonstration.

- No backend database.
- No real user authentication.
- No actual payment processing.
- Shopping cart and wishlist use browser LocalStorage.

## 🎯 Project Purpose

This project was developed as an academic project to practise front-end web development, JavaScript programming, website design, and interactive user interfaces.
